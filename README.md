# my-error-notebook

错题本——记录每一次踩坑，避免重复犯。

## 目录结构

```
my-error-notebook/
├── C-Lang/          # C 语言编程题
│   └── 01-输入n个数求最大最小值/
│       ├── solution.c    # 最终正确代码
│       └── README.md     # 错误分析 + 知识点总结
├── ML-NN/           # 机器学习 / 神经网络
├── Math-Calc/       # 数学 / 微积分
└── assets/          # 截图等附件
```

## 每道题的格式

每道题建一个文件夹，命名 `序号-题目名`，里面两个文件：

- `solution.c` — 最终通过的正确代码
- `README.md` — 错题笔记，包含：
  - 题目描述 + 样例
  - **我犯的错误**（按时间顺序，每版错在哪、为什么错、怎么改）
  - 最终正确代码说明 + 本地验证结果
  - 知识点总结
  - Checklist（下次做同类题逐条对）
