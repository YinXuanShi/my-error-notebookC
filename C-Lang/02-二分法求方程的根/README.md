# 02 - 二分法求方程的根

> PTA 7-5 · 2026-11-04

## 题目

给定 `f(x) = cos(2x) · √x - c`，输入 `c`、`x1`、`x2`（`x2 > x1`，且 `f(x1)` 与 `f(x2)` 异号）。
用二分法求 `f(x) = 0` 在 `[x1, x2]` 内的根，保留 4 位小数。

**样例**

```
输入：1.0 2.0 3.0
输出：2.6844
```

---

## 我犯的错误

### 错误 1：return 漏分号

```c
return sqrt(x)*cos(2.0*x)-c     // ❌
return sqrt(x)*cos(2.0*x)-c;    // ✅
```

编译报错：`error: expected ';' after return statement`

---

### 错误 2：用未初始化的变量初始化别的变量（致命）

```c
double r = x1;    // ❌ 此时 x1 还没被 scanf 赋值
double l = x2;    // ❌ 同上
scanf(...);       // 现在才读入 x1/x2，但 r/l 已经是垃圾值了
```

编译警告：`variable 'x1' is uninitialized when used here`

**修正**：赋值移到 scanf 之后

```c
scanf("%lf %lf %lf", &c, &x1, &x2);
r = x1;    // ✅
l = x2;
```

**核心规则**：`scanf` 之前不要用还没读入的变量初始化别的变量。顺序永远是：

```
声明 → scanf 读入 → 用读入的值做后续操作
```

---

### 错误 3：二分循环里冗余代码（不影响结果，但多余）

```c
if (q < 0) {
    mid = (mid + r) / 2.0;   // ❌ 没用，下一轮被覆盖
    l = mid;
}
```

`mid` 在下一轮循环开头被 `mid = (r+l)/2.0` 重新计算，这里改 `mid` 没有意义。直接 `l = mid` 就够了。

## 知识点总结

### 1. 二分法求根模板

```c
scanf(...);          // 先读入
r = x1; l = x2;      // 再初始化左右边界

for (int i = 0; i < 100; i++) {    // 100 次足够 double 精度
    mid = (r + l) / 2.0;
    if (f(r) * f(mid) < 0) {
        l = mid;       // 根在 [r, mid]，缩右边界
    } else {
        r = mid;       // 根在 [mid, l]，缩左边界
    }
}
printf("%.4f", mid);   // 输出结果
```

**原理**：`f(r)` 和 `f(mid)` 异号 → 根在左半段；同号 → 根在右半段。每次把区间砍半，100 次后区间宽度 < 10^-30，远超 double 精度。

### 2. 变量初始化顺序

```c
// ❌ 错误顺序
double r = x1;     // x1 还没读入
scanf(&x1);

// ✅ 正确顺序
scanf(&x1);
double r = x1;     // 或者分两步: double r; ... r = x1;
```

### 3. 二分法循环次数

- `int` 区间二分：31 次够（2^31 ≈ 21 亿）
- `double` 区间二分：100 次足够（2^-100 ≈ 10^-30）
- 你写的 111 次没问题，只是多了几次无害迭代
