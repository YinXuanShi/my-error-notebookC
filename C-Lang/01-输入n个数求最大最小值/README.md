# 01 - 输入 n 个数求最大最小值

> PTA 7-1 · 2026-11-03

## 题目

输入第一行一个整数 `n`（1 < n < 200），第二行 `n` 个整数（每个 > -10000 且 < 10000）。
输出这 `n` 个整数中的最小值和最大值，中间用一个空格分隔。

**样例**

```
输入：
10
1 2 6 7 8 9 10 3 4 5

输出：
1 10
```

---

## 我犯的错误（按时间顺序）

### 第一版：参数没写类型

```c
int MIN(*p, *n);    // ❌ 参数缺类型
```

编译器看到 `*p` 时不知道 `p` 是什么类型，报错。

**修正**：参数必须写完整类型 → `int MIN(int *p, int n)`

---

### 第二版：调用处多写了类型和多加了 `*`

```c
int a = MIN(p, int n);   // ❌ 调用时多写了 int
int b = MAX(p, *n);      // ❌ 调用时多写了 *
```

编译报错：
```
error: expected expression
   int a=MIN(p,int n);
                   ^
error: indirection requires pointer operand ('int' invalid)
   int b=MAX(p,*n);
                  ^~
```

**这是最核心的混淆点**：

| 场景 | 写法 | 要不要写类型？ |
|---|---|---|
| 声明 | `int MIN(int *p, int n);` | ✅ 要 |
| 定义 | `int MIN(int *p, int n) { ... }` | ✅ 要 |
| **调用** | `MIN(p, n)` | ❌ **不要** |

调用函数时只传变量名，不写类型关键字，不加 `*`。

---

### 第三版：函数体内比较对象选错

```c
int min = p[0];
for (int j = 1; j < n; j++) {
    if (p[0] > p[j]) { min = p[j]; }   // ❌ 每次都跟 p[0] 比
}
```

`p[0]` 是固定值，等于只跟首元素比。如果 `p[0]` 本身不是最小值，后续更小的数会被漏掉。

**修正**：要跟当前的 `min` 比：

```c
if (p[j] < min) min = p[j];    // ✅ 跟当前最小值比
```

MAX 同理：`if (p[j] > max) max = p[j];`

## 知识点总结

### 1. 数组传给函数的三步法

```c
// 第一步：前置声明（写在 main 上面）
int MIN(int *p, int n);

// 第二步：在 main 里调用（只传变量名，不写类型）
int a = MIN(p, n);

// 第三步：在 main 下面定义
int MIN(int *p, int n) {
    // 函数体
}
```

### 2. 数组名就是指针

`int p[100]` 和 `int *p = malloc(...)` 传给函数时写法一样：
- 传数组：`MIN(arr, n)` —— `arr` 自动退化为 `int*`
- 传 malloc 指针：`MIN(p, n)` —— `p` 本身就是 `int*`

### 3. 在函数内找最值的正确模板

```c
int min = p[0];              // 假设第一个是最小值
for (int j = 1; j < n; j++) { // 从第二个开始遍历
    if (p[j] < min)           // 跟 min 比，不是跟 p[0] 比
        min = p[j];
}
return min;
```

### 4. malloc 三件套

```c
int *p = malloc(n * sizeof(int));   // 分配
if (p == NULL) return 1;             // 判空
// ... 用 p ...
free(p);                             // 释放
p = NULL;                            // 置空（好习惯）
```

## Checklist（以后做这类题逐条对）

- [ ] 声明处参数写完整类型：`int *p, int n`
- [ ] 调用处只写变量名：`MIN(p, n)`，不写 `int`、不加 `*`
- [ ] 函数体内跟 `min`/`max` 比，不是跟 `p[0]` 比
- [ ] malloc 之后判空
- [ ] 用完 free + 置空
